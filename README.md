Подробнее про методы оптимизации: https://github.com/d2min/optimyze_methods/

Установка зависимостей:
```commandline
python -m pip install -r requirements.txt
```

## 3D-просмотр облаков точек

На шаге «Предобработка» доступен встроенный интерактивный просмотрщик
облаков точек. Он открывает файлы `.xyz`, `.txt`, `.pts`, `.las` и `.laz`
и не требует отдельной установки SmartLaser Point Viewer.

Основные возможности:

- исходная палитра классов SmartLaser, девять точных градиентов высоты и
  отображение RGB-цветов из файла;
- управление видимостью, цветом, абсолютным размером `0–10` и отдельным
  множителем точек каждого класса;
- перспективная камера с исходным углом обзора `75°`, настраиваемый FOV,
  ортографическая камера и шесть стандартных видов;
- отдельные режимы орбитальной камеры и свободного полёта с регулируемой
  скоростью: `WASD` — движение, `Space` — вверх, `Shift` — вниз, ЛКМ — обзор;
- вращение с инерцией, перемещение, масштабирование, клавиатурная навигация
  и счётчик FPS;
- постоянные информационные метки, маркер точки под курсором и рулетка с
  несколькими ломаными и подписями каждого отрезка; маркеры и линии являются
  глубинными 3D-объектами сцены и корректно перекрываются облаком;
- интерактивный 3D-профиль и отдельная 2D-развёртка выбранного коридора;
- ограничение диапазона высот, визуальные границы и профильный срез;
- настоящий экранный Sobel-фильтр для обнаружения краёв;
- светлая и тёмная темы, переключатели сетки и градиентного фона;
- меню «Файл»: открыть файл, повторно открыть последний файл, сделать снимок
  и конвертировать в XYZ, TXT, LAS или LAZ;
- сохранение параметров между запусками и при открытии следующего файла;
- перетаскивание поддерживаемого файла прямо в окно просмотрщика.

Обычный сценарий запуска:

1. Запустите приложение командой `python main.py`.
2. На шаге «Предобработка» выберите папку с облаками точек.
3. Выделите нужный файл в таблице и нажмите `Открыть в 3D`.

Чтобы сразу заполнить папки исходных данных и результатов без диалогов
выбора, передайте их при запуске:

```commandline
python main.py --input-dir "example/input_dataset" --output-dir "example/output_dataset"
```

Папки должны существовать. Приложение заполнит поля, но не начнёт обработку
автоматически: для этого нажмите «Оптимизировать данные».

Для изолированной проверки просмотрщика на примере из репозитория:

```commandline
python scripts/run_point_cloud_viewer_demo.py
```

Можно сразу передать собственный файл:

```commandline
python scripts/run_point_cloud_viewer_demo.py "/путь/к/облаку.xyz"
```

На Windows PowerShell после клонирования проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\run_point_cloud_viewer_demo.py
.\.venv\Scripts\python.exe main.py --input-dir "example\input_dataset" --output-dir "example\output_dataset"
```

Для свободного перемещения откройте раздел «Камера», выберите «Свободный
полёт», задайте скорость и кликните по 3D-сцене, чтобы она получила фокус
клавиатуры. После этого используйте `WASD`, `Space` и `Shift`.

Если macOS сообщает, что не найден Qt-плагин `cocoa`, снимите системный флаг
скрытых файлов с виртуального окружения и повторите запуск:

```commandline
chflags -R nohidden .venv
```

Для отображения требуется рабочий драйвер OpenGL. По умолчанию просмотрщик
читает все точки, а индикатор внизу сцены показывает прогресс. Это повторяет
поведение SmartLaser, но для очень большого файла потребует больше оперативной
и видеопамяти. При необходимости можно снять флажок «Загружать все точки без
ограничения»: тогда будет построена равномерная выборка до 1 500 000 точек, и
просмотрщик предупредит, что при конвертации сохранится именно эта выборка.

## Просмотр результатов обучения

Экран «Обучение» читает готовые артефакты PointNet++ из репозитория
`lidar-segmentation-kubsu/mihail-pointer-experiment`. Нажмите
«Выбрать результаты» и укажите папку конкретного запуска `runs/<run_id>`
или вложенную папку `results`.

Ожидаемая структура:

```text
runs/<run_id>/
├── history.csv
├── config.json
├── metadata.json
└── results/
    ├── metrics.json
    ├── metrics.csv
    └── per_scene_metrics.csv
```

Интерфейс строит четыре графика из `history.csv`, таблицы метрик из CSV/JSON
и матрицу ошибок из `metrics.json`. PyTorch и файл весов `best_pointnet2.pt`
для просмотра результатов не требуются. Все пути обрабатываются через
`pathlib`, поэтому можно выбирать обычные папки Windows.

### Быстрая ручная проверка интерфейса

В репозитории есть небольшой демонстрационный запуск
`example/training_run_demo`. Он нужен только для проверки интерфейса и не
выдаётся за результат реального обучения.

Обычный сценарий:

1. Запустите приложение командой `python main.py`.
2. Нажмите шаг `3 — Обучение` в верхней части окна.
3. Нажмите `Выбрать результаты`.
4. Выберите папку `example/training_run_demo`.
5. Переключите вкладки `Графики`, `Метрики`, `Матрица ошибок`. На вкладке
   `Графики` проверьте обе круглые стрелки: они циклически переключают четыре
   реальных представления данных из `history.csv`.

Чтобы сразу открыть заполненный экран без диалога выбора папки:

```commandline
python scripts/run_training_demo.py
```

На Windows PowerShell после клонирования проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\run_training_demo.py
```

Для проверки загрузчика можно также выбрать папку `results` внутри
демонстрационного запуска. Если выбрать произвольную папку, интерфейс должен
показать понятное сообщение об отсутствующих `history.csv` или `metrics.json`.

Проверки разработчика:

```commandline
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m ruff check training_results.py screens/training.py tests
```
